## 一、功能及使用范围

随行定位是开放源码的设备开发与定位测试工具，提供蓝牙 / USB 定位、地图搜索、坐标选点及相关本地管理功能。请仅操作自有或已获明确授权的设备，遵守适用法律及相关平台规则。请勿用于欺诈、作弊、规避监管、侵害他人权益或其他违法活动；勿将它作为驾驶、救援、医疗或其他人身安全决策的定位依据。

## 三、数据与隐私告知

**设备连接和定位数据通过本机蓝牙或 USB 与所连接设备交换；坐标、收藏、地图配置和连接设置可保存在本机。使用在线地图、地点搜索或地址解析时，第三方地图服务会收到相应搜索词、地址、视野 / 参考坐标等请求数据及通常的网络连接信息。地图 Key 会发送给对应服务以完成鉴权。**

根据所选服务，在线地图与搜索可能连接高德、Photon、OpenStreetMap 及其瓦片服务。自动搜索模式可能请求多个地图来源。第三方依照各自条款和隐私政策处理请求；请勿输入不希望交给对应服务的秘密信息。直接输入坐标可用于设置目标，在线地图和搜索需自行决定是否使用。

**主动检查更新或下载更新会连接本项目 GitHub 仓库及 GitHub 的分发服务；请求涉及公开版本信息、更新文件和通常的网络连接信息。本项目未配置将蓝牙身份、地图 Key、收藏或手机配对资料上传到开发者服务器的功能。**

本机记录协议版本及同意时间以判断是否需要再次确认。应用不会因本页同意而自动获得蓝牙、通知或安装来源权限；相关权限仍由操作系统独立控制。卸载清除数据或手动删除本地数据后可能需要重新同意。开源源码和随包许可证可独立查阅。
