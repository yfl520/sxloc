# 随行定位 · Flutter 中文桌面版

基于 D1ngtalk/iap2loc 改造的 Windows 桌面客户端，当前测试版本 1.1.3。界面由 Flutter 绘制，采用 macOS 风格的侧边栏、统一工具栏、红黄绿窗口按钮、Cupertino 控件与局部玻璃材质。

1.0.2 界面调整：地图选点与收藏位置面板增加收起/展开按钮，点击对应侧栏或 Ctrl+F 可重新展开。应用目标时按钮显示进度，成功后短暂显示绿色“目标已更新”，地图图钉轻弹并显示三秒地点与坐标提示。按钮附近显示具体错误并可重试；当前目标、最近更新时间和发送状态常驻显示，底栏在详情收起后仍显示发送状态。

本次目标与本机发送提交记录按目标代次匹配；显示“正在发送本次目标”表示当前坐标的数据近期已提交本机 iAP2 链路，不能证明手机已收到或采用，也不能把旧坐标累计条数作为本次发送成功依据。多设备显示本次目标的近期发送台数，并显示发送异常。没有更改手机订阅周期、跳变帧或定位源选择逻辑。

1.0.3：移除手机定位刷新指引入口、指引面板及计时功能，保留面板收起和定位反馈增强。只生成测试运行目录，未生成新安装包或压缩包，未启动成品、操作界面或连接手机验收。

1.0.1 界面调整：设备面板可收起/展开，失败或停止的连接记录支持 × 移除及批量清除；已连接设备禁用重复连接。右侧改为“坐标 / 参数 / 地图”三个固定标签，经纬度并排，当前目标和应用按钮固定在底部，内容区域可滚动。此版本先交用户测试，暂未重新生成安装包和压缩包。

## 1.1.3 关于与界面整理

侧栏底部和设置中增加“关于随行定位”，显示版本、开源项目名“ios定位”、原项目 iap2loc 与实验身份来源 DiPlay 的 GitHub 地址和署名。地址支持打开与复制；当前尚未发布自己的仓库，页面明确显示待发布。

移除诊断日志入口、复制日志面板、详细协议日志开关和桥接日志缓存。连接状态、发送状态和错误提示继续显示。

创建仓库后，构建脚本传入 `-ProjectGithubUrl 'https://github.com/你的用户名/仓库名'` 即可填入自己的项目地址；也可修改 `FlutterApp/lib/app_info.dart` 中的配置。原项目链接独立保留，不将其作为本项目的新仓库。仍仅交付测试运行目录，正式安装包等待用户验证。

## 1.1.2 地点搜索同步

同步安卓端的输入联想、村庄与完整地址补查。输入两个及以上字符，暂停输入后显示联想；回车或点击箭头执行完整搜索。中文输入法组词期间不发起查询。

已有坐标的地点直接选中；没有坐标的建议保留原省市区、乡镇与行政区编码，点击后按地点 ID、完整地址搜索、正向地理编码依次补查。地址匹配显示村庄、乡镇等返回级别，同名或近似结果供用户核对后选择。已知不同行政区的同名点不会作为原地点直接选中；缺少地区信息的相关候选仍需确认。服务没有提供坐标时不会使用零点或地图中心代替。

“自动选择”在高德失败或没有可用坐标时补查 Photon 开放地图；指定高德或开放地图则仅查询所选服务。搜索有取消和超时处理，旧响应不会覆盖新结果；选点、收起搜索或打开设置会停止待处理查询。查不到的地点仍可直接在地图上选点，选中后需要点击“应用定位”。第三方数据的覆盖和精度会影响具体地点结果，不能保证所有地名都有精确坐标。

本次只生成可运行测试目录，不生成安装器或 ZIP，不启动应用、不连接手机。离线搜索回归涵盖无坐标村名、过期 ID、同名与区县确认、空结果和错误兜底、取消、缓存与异常坐标。

## 1.1.1 开发者模式入口

“我的设备 → USB 开发者”增加“显示开发者模式入口”。设置里没有开发者模式时，先插入数据线、解锁并信任电脑，刷新并选中手机，再点击该按钮。手机确认后，重新打开“设置 → 隐私与安全性”并滑到底部，手动开启、按手机提示重启及确认，然后返回应用连接定位。

该操作只请求显示入口，不自动开启、不触发重启、不代替用户确认。不支持该入口服务或被设备限制时显示错误；iOS 16 以前不需要此开关，已开启时提示直接连接。仍只交付测试目录，由用户进行手机验证。

## 1.1.0 USB 开发者定位测试版

“我的设备”增加“蓝牙 / USB 开发者”切换。USB 模式使用开发者模拟定位服务；连续改点复用同一个会话，地图、地点搜索、收藏和手动坐标共享当前目标。目的在于避开蓝牙配件定位源的切换问题，是否在你的手机和目标 App 中无需切换 Wi-Fi／定位开关生效，仍须实机确认。

本版只交付可运行测试目录，未生成安装器或 ZIP。先退出旧版，再打开测试目录中的“随行定位.exe”。所有旁边文件均须保留，尤其是 `core/usb`；已捆绑独立 Python 运行时，使用者无需安装 Python。

| iOS 系统分支 | 已实现的连接方式 | 条件与实测范围 |
| --- | --- | --- |
| 17 以前 | USB lockdown + 传统模拟定位服务 | 需要对应系统的开发者镜像；16 及以后还需开发者模式 |
| 17.0–17.3 | USB 初始配对 + RemotePairing 同网隧道 + DVT | 手机与电脑需在同一局域网，发现服务及网络条件会影响可用性；本版不提供此范围的纯 USB 内核隧道 |
| 17.4 及以后（含 18、26、27 的版本判断） | USB 用户态隧道 + DVT | 通常无需管理员；16 及以后需开发者模式；遇到服务缺失时准备匹配镜像，27 的镜像准备通过 RSD 处理 |

上述为代码适配范围，全部尚未实机验证，不承诺任意版本或测试版系统都可用。Apple 协议、开发者镜像和上游组件可能限制特定系统构建；失败时显示中文原因，不会套用不匹配的旧版连接流程。

使用步骤：

1. 数据线连接手机，在手机上解锁并信任电脑。电脑需有 Apple Devices／iTunes 提供的 Apple Mobile Device 设备服务。
2. 在“我的设备”切换到“USB 开发者”，点击刷新并选择手机。iOS 16 及以后请先在手机设置中开启开发者模式并完成系统要求的确认；找不到时点击应用内“显示开发者模式入口”。
3. 选好目标，点击“连接并使用当前目标”。首次缺少开发者镜像时会显示准备状态并联网下载；可以取消，不会自动重启手机或修改开发者模式。
4. 连接后换地点并点击“应用定位”。后台立即向原会话提交新经纬度，无需每次重新连接。仅 USB 一台设备，蓝牙模式保留原有多设备支持。连接另一种模式时先停止现有模式，避免定位来源冲突。
5. 点击“停止模拟”。显示“已发送停止模拟指令”仅表示指令发送，恢复实际位置以手机为准；若拔线或服务异常导致指令无法发送，会保留未确认提示。

USB 开发者通道只发送经纬度，使用与现有目标相同的一次性随机偏移结果。高度、精度、速度、卫星数及周期等扩展参数用于蓝牙 iAP2。未重新加入手机定位开关指引或十秒计时。

## 安装与启动

- Windows 10 2004（19041）及以上或 Windows 11，x64；蓝牙模式需要经典蓝牙适配器；USB 模式需要数据线与 Apple 设备服务。
- 双击“随行定位-安装.exe”，按中文向导安装。默认安装到当前用户的 `AppData\Local\Programs\SuixingLoc`，可创建桌面快捷方式。
- 也可完整解压“随行定位-便携版.zip”，进入“随行定位”文件夹，双击“随行定位.exe”。请保留旁边的 `data`、`core` 文件夹及所有 DLL。
- 已随包携带 Flutter 引擎、C++ 运行库与自包含 .NET 定位组件，无需安装 Flutter、.NET SDK、Python、WebView2 或 Visual Studio。
- 正常启动直接显示桌面窗口。主程序与后台组件均按 Windows GUI 程序构建，后台通过匿名管道通信，USB 子进程隐藏窗口，不打开控制台或浏览器，也不监听本地 HTTP 端口。
- 本版尚未签署商业代码签名证书。

## 地点搜索与地图选点

1. 左上搜索框输入地名、景点或完整地址，暂停后显示联想；按回车或点击箭头进行完整搜索。
2. 点击结果选择位置；没有坐标的建议会继续查找，同名或近似匹配需核对完整地址和匹配级别。也可以直接点击地图选点。
3. 右侧检查经纬度及参数，点击“应用定位”。连接设备时，如有待应用的修改，会先提交参数。
4. 收藏当前位置后，可从侧栏或收藏页面再次选择；删除收藏需要确认。

搜索默认“自动选择”：未填写高德 Key 时使用 Photon 开放地图搜索；填写高德 Web 服务类型 Key 后优先使用高德联想、POI 搜索与地址解析，失败或没有可用坐标时再补查开放地图。国内详细地址建议配置自己的高德 Key，第三方服务的覆盖、网络可用性和配额由相应服务决定。可在设置中填写优先搜索城市，也可指定自己的 Photon HTTPS 服务地址。

搜索框也支持 `纬度,经度`，如 `31.230400,121.473700`。默认按 WGS-84 解析；高德坐标可输入 `gcj:31.228458,121.478223`。右侧坐标字段及实际发送目标统一使用 WGS-84；高德底图和搜索结果会自动进行 GCJ-02 转换。切换底图不会改变实际发送坐标。

地图可切换高德中文底图或 OpenStreetMap。搜索和加载在线地图需要联网；无蓝牙适配器时仍可使用搜索、地图选点与收藏。

## 连接手机

1. 在 Windows 蓝牙设置中先完成与 iPhone 的配对。
2. 打开软件的设备页面，刷新并选择设备，点击“连接设备”。软件启动时不会自动连接手机。
3. 查看握手、识别、认证、订阅及定位发送状态。认证完成且手机订阅定位后才发送定位数据。
4. 点击“断开”或“停止全部设备”结束发送；关闭应用也会请求释放连接。

支持高度、精度、周期、速度、航向、卫星数、定位质量，以及位置随机偏移和精度随机变化。所有已连接设备共享当前目标位置。软件中“已应用”表示目标已交给定位组件，并不等于手机已经接受；实际状态以设备认证、订阅和发送记录为准。iOS 会融合多种定位来源，最终效果需要在你的手机上验收。

内置的是从公开 DiPlay v0.2.22 APK 提取的实验身份，详见“身份来源说明.md”。设置中支持导入带相应资源的 APK，或导入 PKCS#8 私钥（同一文件夹须有 `certificate.p7b`）；也可切回内置身份。身份变更对之后的新连接生效。

USB 组件按上游规则在当前用户 `~/.pymobiledevice3` 中缓存配对记录和开发者镜像，不写入程序目录。请勿把配对记录发送给其他人或放入源码包。

## 数据与快捷键

用户数据位于 `%LOCALAPPDATA%\SuixingLoc`：

| 文件 | 用途 |
| --- | --- |
| `desktop.json` | 上次位置、定位参数、搜索设置与历史；高德 Key 按当前 Windows 用户加密 |
| `iap2loc.json` | 配件信息与收藏位置 |
| `identity.dpapi` | 用户导入的身份材料，按当前 Windows 用户加密 |

设置中可打开数据目录。卸载和升级保留这些用户数据；便携版也使用此目录。DPAPI 加密数据不可直接迁移给另一个 Windows 用户使用。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+F` | 定位到搜索框 |
| `Ctrl+Enter` | 应用定位 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+W` | 关闭软件 |

## 从源码构建

构建环境：Flutter stable 3.50.0 / Dart 3.14.0、.NET SDK 10.0.404、Visual Studio C++ 桌面开发工具、Windows SDK；生成中文安装 EXE 还需 Inno Setup（本次 7.1.1）。Dart 依赖由 `FlutterApp/pubspec.lock` 固定；USB 组件为 pymobiledevice3 11.55.0 + CPython 3.14.7 x64，89 个 wheel 的完整版本和 SHA256 由 `Bridge/UsbWorker/requirements.lock` 固定。源码构建 USB 运行时需要本机 Python 3.14 x64 + pip，发布脚本使用 `scripts/prepare-usb-runtime.ps1` 校验、缓存并复制运行时。

在源码根目录的 PowerShell 中执行：

```powershell
.\scripts\import-desktop-identity.ps1
.\scripts\publish-flutter.ps1 `
  -Flutter 'C:\tools\flutter\bin\flutter.bat' `
  -Dotnet 'C:\Program Files\dotnet\dotnet.exe' `
  -InnoCompiler 'C:\tools\innosetup\ISCC.exe' `
  -BuildRoot 'C:\SuixingLocBuild' `
  -OutputRoot 'C:\SuixingLocRelease'
```

身份导入脚本固定下载官方 DiPlay v0.2.22 APK 并校验 SHA256；也支持 `-ApkPath` 指向本地的同一官方 APK。材料不会放进源码压缩包。发布脚本仅编译和打包，不启动应用。`OutputRoot` 下的“随行定位”文件夹须不存在，重复发布时请指定新的输出目录。

先编译供用户试用时，增加 `-TestBuild`，只生成可以直接运行的文件夹，不生成安装包或压缩包。

脚本会把 Flutter 源码复制到英文构建目录，并在必要时为 SDK 创建英文路径联接，避免 Windows 原生工具链的中文路径编码问题。构建目录可在构建结束后自行清理。应用的 Windows 用户目录、安装目录可以使用中文；本次未做安装运行验收。

架构：`FlutterApp/lib` 负责界面、Flutter 地图、交互与匿名管道客户端；`Bridge` 负责 JSON Lines 命令、配置、搜索及定位会话；`Engine`、`Protocol`、`Transport` 保留并改进原项目核心。`Desktop` 中五个纯服务源码由 Bridge 复用，旧 WPF 界面不参与 Flutter 发布。

源码按原项目 GPL-3.0 许可提供，完整许可见 `LICENSE`。第三方许可见安装目录中的 `licenses`、Flutter 自动生成的许可集合，以及“第三方组件说明.md”。
